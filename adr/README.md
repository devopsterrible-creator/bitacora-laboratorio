# ADR — Architecture Decision Records

Cada ADR registra UNA decisión de arquitectura: el contexto, la decisión, su
estado y las consecuencias. Sirve para no reabrir discusiones ya cerradas y
para entender, meses después, *por qué* algo se hizo así.

- Formato de archivo: `ADR-NNN-titulo-corto.md`
- Estados: `Propuesta` / `Aceptada` / `Reemplazada por ADR-XXX`
