# Glosario técnico (ES / EN)

| Español | English | Qué es |
|---|---|---|
| Proxy inverso | Reverse proxy | Servidor que recibe del exterior y reenvía a un servicio interno |
| Socket interno | Internal socket | Canal de comunicación local, no expuesto a internet |
| Cortafuegos | Firewall | Filtra qué puertos/tráfico entran y salen |
| Despliegue | Deployment | Publicar la app en producción |
| Reinicio elegante | Graceful restart | Reiniciar sin cortar peticiones en curso |
| Endurecimiento | Hardening | Reducir la superficie de ataque |
| Copia de seguridad | Backup | Respaldo de datos para recuperación |
| Bitácora | Lab notebook / log | Registro cronológico de lo ejecutado |
| Registro de decisión | ADR (Decision Record) | Documento de UNA decisión de arquitectura |
